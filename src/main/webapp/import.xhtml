Импорт

Импорт маршрутов

JSON-массив: до 1000 маршрутов, файл до 1 МиБ. При ошибке весь импорт отменяется.

В каждой записи задайте name, coordinates (x, y), from (x, y, z), distance и rating. Поле to необязательно. Названия вложенных локаций необязательны. Локации создаются вместе с маршрутом. ID и дата создания назначаются сервером.
