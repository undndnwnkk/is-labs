## Вывод об изоляции

READ COMMITTED оставлен и явно задан у datasource. На нём общая транзакционная блокировка писателей
устраняет гонку проверка/вставка, а версия объекта защищает от устаревших форм.
Проверка подтвердила требуемые инварианты; повышения уровня изоляции не потребовалось.
Прогон проверяет перечисленные конкурентные сценарии, а не все возможные расписания транзакций
или производительность под большой нагрузкой.

## Исправления, обнаруженные при запуске

В исходном compose.yaml ключ `pft,services` мешал запуску — исправлен на `services`.
Из полей координат карточки убраны `f:convertNumber`: старый конвертер искажал большие значения
при повторном сохранении. Используются стандартные конвертеры типов, как в форме списка.
Вставка metadata шаблона вынесена из h:head, чтобы viewParam/viewAction находились на уровне view.
JDBC-драйвер скачивается без транзитивных зависимостей, которые контейнеру не нужны.
Для JMeter выбрана Java 17: встроенный Groovy 3.0.20 не поддерживает Java 23 этой машины.
